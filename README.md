# Stacker-Game

// Stacker Game 🕹️

A simple and fun /*Stacker Game*/ built with Arduino and simulated using Proteus. The goal of the game is to stack blocks perfectly on top of each other to reach the highest score.

// Features
* 🎮 Engaging arcade-style gameplay.
* ⚡ Real-time hardware simulation.

// Files Included
* `*.ino` - The core Arduino source code.
* `*.pdsprj` - The Proteus simulation design file.
//
//

// (Stacker เกม) 🕹️

โปรเจกต์ /*เกม Stacker*/ พัฒนาโดยใช้บอร์ด Arduino และจำลองการทำงานของฮาร์ดแวร์ผ่านโปรแกรม Proteus โดยผู้เล่นจะต้องกดปุ่ม Enter เพื่อวางบล็อกให้ตรงล็อกพอดีเพื่อสะสมคะแนนให้ได้สูงที่สุด

// ฟีเจอร์เด่น
* 🎮 ระบบการเล่นเกมแนวอาร์เคดที่เข้าใจง่ายและสนุกสนาน
* ⚡ จำลองการทำงานของฮาร์ดแวร์แบบ Real-time

// ไฟล์ในโปรเจกต์นี้
* `*.ino` - โค้ดหลักภาษา C/C++ สำหรับ Arduino
* `*.pdsprj` - ไฟล์จำลองวงจรและฮาร์ดแวร์ในโปรแกรม Proteus
